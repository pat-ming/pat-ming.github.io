Agentic Workflow Plugin — Autonomous End-to-End Project Builder

Aug 2026 – Aug 2026

Agent orchestration · Developer tooling · Autonomous software builds

Most AI coding tools help you write code faster. This one builds the whole project without me in the loop — from a one-line prompt to a planned, tested, committed repository — in my own development style, encoded as a Claude Code plugin.

  • An orchestrator command decomposes the prompt into a dependency-ordered plan, then delegates each phase to a fresh headless agent session. The agents share no memory and coordinate only through git and the filesystem, so the system stays legible and every decision leaves a trace.
  • Correctness is fixed up front by machine-checkable verifiers — one per phase — frozen by hooks so the implementing agents physically cannot edit or grade their own tests. Same deterministic-verifier, anti‑reward‑hacking philosophy as my RL work: no LLM judge in the loop.
  • Hand-built from Claude Code primitives: a slash-command orchestrator, three specialized subagents (verifier authoring, dead-code cleanup, finalization), guardrail hooks, and a phone-notification skill.
  • Each phase makes an implementation commit and a cleanup commit, with automatic rollback to the last good state if cleanup regresses any verifier; a final from-scratch clone-and-run check proves the build reproduces.
  • Runs unattended, pushing progress and failure notifications to my phone so a long build needs no babysitting.

RL Environment for Mathematical Construction and Counterexample Tasks

Jun 2026 – present

Post-training · Reinforcement learning · LLM evaluation

Most math benchmarks ask a model for an answer. This one asks it to construct an object — a matrix with a given property, a counterexample to a plausible-sounding claim — which is much harder to fake and much harder to grade.

  • 314 tasks spanning linear algebra, abstract algebra, and real analysis.
  • Scored by 28 hand-designed verifiers. No LLM judge anywhere in the pipeline, so the reward signal is deterministic and inspectable.
  • Red-teamed the verifiers against reward hacking, surfacing and closing 735 cases where a wrong object was being accepted.
  • MiniMax-M2, a frontier model, scores 79% on the hardest tier — leaving real headroom for the benchmark to be useful.

WUSTL Research Matchmaker

Jan 2026 – Apr 2026

Retrieval-augmented generation · Information retrieval

Finding a faculty member whose research actually matches your interests is a three-hour slog through department pages written in twelve different formats. This turns it into a five-minute query.

  • Multi-vector RAG model returning ranked compatibility scores against WashU faculty from a plain-language description of your interests.
  • Custom scraper built to tabulate 1,584 STEM faculty and their research profiles into a consistent, queryable corpus.
  • Being prepared for distribution to first-year STEM courses.
